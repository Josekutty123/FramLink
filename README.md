# FarmLink ERP

FarmLink ERP is an Agricultural Resource and Marketplace Management System built with Django.

## Features
- Admin Dashboard for managing farmers, deliveries, and customers.
- Farmer Portal for adding agricultural products and viewing sales.
- Customer Portal for browsing and bargaining on products.
- Delivery Personnel Portal for accepting and managing deliveries.

## Setup
1. Clone the repository
2. Install requirements using `pip install -r requirements.txt`
3. Configure the `.env` file with your database credentials and secret key
4. Run migrations using `python manage.py migrate`
5. Start the server using `python manage.py runserver`
